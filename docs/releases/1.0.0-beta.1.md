# StreamGuard 1.0.0-beta.1

First public beta release.

## Highlights

- Configurable stream-gated survival enforcement for Paper/Spigot 1.20.1+.
- Twitch and YouTube verification.
- Optional player setup flow.
- Persistent and temporary admin bypasses.
- English and Spanish ready-to-edit configs.
- Optional live feed API for companion web walls.
- Live feed metadata enrichment for thumbnails, titles, viewer counts, and live-since timestamps
  when provider APIs return them.

## Notes

This is a beta release. Configuration names and feed details may still receive small refinements
before the first stable `1.0.0` release.
